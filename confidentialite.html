Quelles données sont traitées, et où

Les informations que vous saisissez dans Cadence (contrats, cachets, situation personnelle, dépenses professionnelles) sont stockées :

  • Localement dans votre navigateur (via localStorage), sur votre appareil uniquement.
  • Optionnellement, dans votre propre Google Drive — si vous choisissez d'activer cette option pour sauvegarder vos justificatifs ou vos exports.

Dans les deux cas, ces données ne transitent par aucun serveur appartenant à l'éditeur de Cadence. Il n'existe pas de base de données centrale : personne d'autre que vous n'a accès à ce que vous saisissez.

Connexion à Google Drive

Si vous connectez votre compte Google, Cadence demande uniquement l'autorisation drive.file — un accès limité aux seuls fichiers que Cadence crée elle-même (par exemple votre export PDF de frais réels). Cadence ne peut pas voir, lister ou modifier le reste des fichiers de votre Drive.

Vous pouvez révoquer cet accès à tout moment depuis les paramètres de sécurité de votre compte Google.

Vos données, vos responsabilités

Le stockage étant local, la perte de votre navigateur, un changement d'appareil ou un vidage du cache entraîne la perte des données saisies. Cadence propose un export/import JSON pour vous permettre de sauvegarder et transférer vos données vous-même.
